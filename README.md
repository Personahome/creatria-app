# Creatria App

Creatria App can convert any media file in MOV format into Apple Live Photo. Creatria App is compatible with macOS 26 and above, and your Mac needs to be equipped with Apple M or A series chips.

**Are there any restrictions on MOV format media files?**
Yes. When using Creatria App with Open Personahome resources, your MOV media file must have a total duration of 30 seconds or less. MOV files are compatible with all converted media formats (such as MP4), but the prerequisite is that you have already converted them to MOV files using other tools.

**Where will the converted files be saved?**
The converted files will be saved in the Mac's built-in Photos App. This means your Photos App needs to be available, and you must have used the Photos App before using Creatria App. Creatria App will ask for permission when saving Live Photos.

**Will Creatria App upload my private data?**
No, it will not.
