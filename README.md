# 📸 Creatria App

> Convert MOV files to Apple Live Photos seamlessly on macOS.

---

## Overview

Creatria App allows you to convert any media file in **MOV format** into an **Apple Live Photo**. It is compatible with **macOS 26+** and requires a Mac with **Apple M-series or A-series** chips.

---

## FAQ

### Are there any restrictions on MOV format media files?

**Yes.** When using Creatria App with Open Personahome resources, the total duration of your MOV file must be **30 seconds or less**.

> **Note:** MOV files are compatible with all converted media formats (e.g., MP4). However, you must use other tools to convert them to MOV format before importing.

---

### Where will the converted files be saved?

Converted files are saved directly to the Mac's built-in **Photos App**.

> **Note:** Make sure the Photos App is available and has been launched at least once before using Creatria App. The app will request permission when saving Live Photos.

---

### Will Creatria App upload my private data?

**No.** All processing is performed locally on your device. No personal data is uploaded to any server.

---

## System Requirements

- macOS 26 or later
- Apple M-series or A-series chip
- Photos App (must be set up and accessible)
